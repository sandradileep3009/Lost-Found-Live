# Lost & Found Live Dashboard

Real-time frontend dashboard for an AI-powered Lost & Found and crowd-safety system.

### Features

* Live camera monitoring
* Detection & zone overlays
* Real-time alerts
* Object search
* Camera health monitoring
* Hand-in desk form

### Tech Stack

HTML • CSS • Vanilla JavaScript • REST API • WebSockets

Built for the **Godavari Pushkaralu 2027** rehearsal system.
